# 任科翰 · 个人主页

一个**单文件、零依赖、零构建**的个人主页，面向四川传媒学院 2026 级计算机科学与技术本科 02 班任科翰。

整个站点只有一份 `index.html`（HTML + CSS + 原生 JS 全部内联），双击即可打开，也可以直接丢到任意静态托管上运行。

---

## 技术栈

| 层面 | 方案 |
| --- | --- |
| 结构 / 样式 / 脚本 | 原生 HTML5 + CSS3 + Vanilla JS，全部内联在单个文件中 |
| 布局 | CSS Grid + Flexbox，`clamp()` 实现流式字号与间距 |
| 主题 | CSS 自定义属性（Design Tokens），`html[data-theme]` 切换明暗 |
| 字体 | 纯系统字体栈（衬线 / 无衬线 / 等宽），不加载任何外部字体 |
| 依赖 | **无**。无框架、无打包、无 CDN、无网络请求 |

---

## 功能特性

**内容与叙事**

- 11 个内容章节：关于我 / 数字速览 / 近期碎片 / 兴趣志 / 能力技能 / 一路走来 / AI 新手村 / 做事原则 / 四年规划 / 最近的我 / 镜头之下 / 联系方式
- 全站中文文案，配合英文小标签（`About` / `Numbers` / `Roadmap`…）做排版对仗

**视觉与交互**

- 明暗双主题切换，偏好写入 `localStorage`
- 固定顶栏 + 右上角下拉目录菜单（含背景遮罩、逐项入场动画）
- 左侧章节指示轨（≥1340px 显示），滚动自动高亮当前章节
- 顶部阅读进度条
- 首屏姓名遮罩上浮动画、旋转徽章、星光点缀
- 背景层：极光渐变 + 细网格 + 颗粒噪点 + 飘落花瓣
- 滚动进入视口时元素渐显（`IntersectionObserver` 驱动）
- 数字滚动计数、技能条进度填充、跑马灯（ticker）
- 图片画廊：网格拼图 + 悬停缩放 + 渐变字幕

**实用功能**

- 4 个「板块」（board）分页导航，每块结尾有上一板块 / 下一板块切换
- 背景音乐开关（BGM），音源以 base64 内嵌，可离线播放
- 后台编辑模式：密码登录 → 全站文字 `contenteditable` → 保存到文件 / 导出 HTML
- 完整响应式：1000px / 860px / 640px / 520px 多档断点适配
- 无障碍：`prefers-reduced-motion` 全面降级、`aria-*` 标注、键盘焦点样式
